# 🚀 Astro Website

A modern website built with [Astro](https://astro.build), HTML, and CSS.

## Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The site will be available at `http://localhost:3000`

### Project Structure

```
astro-website/
├── src/
│   ├── pages/          # Routes (every .astro file = a page)
│   ├── layouts/        # Reusable layouts
│   ├── components/     # Reusable components
│   └── styles/         # Global styles
├── astro.config.mjs    # Astro configuration
└── package.json        # Project dependencies
```

### Building

Build for production:
```bash
npm run build
```

Preview the build:
```bash
npm run preview
```
